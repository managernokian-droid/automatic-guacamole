# 🛞 Аналіз цін шин Nokian

Streamlit-застосунок для аналізу та моніторингу цін шин від постачальників відносно рекомендованого прайсу Nokian.

---

## Модулі

| Модуль | Сторінка | Статус | Опис |
|--------|----------|--------|------|
| Головна | `app.py` | ✅ Готово | Навігація і стан сесії |
| Аналіз цін | `pages/01_analysis.py` | ✅ Готово | Каскадні фільтри, графіки, експорт |
| Моніторинг | `pages/02_monitoring.py` | 🔧 Фаза 2 | Нарушення Nokian + Telegram |
| Динаміка цін | `pages/03_price_dynamics.py` | 🔧 Фаза 3 | Тренди і прогнози |
| Нетто-ціни | `pages/04_net_prices.py` | 🔧 Фаза 3 | Розрахунок нетто |

---

## Швидкий старт

```bash
# 1. Встановити залежності
pip install -r requirements.txt

# 2. Запустити застосунок
streamlit run app.py
```

Застосунок відкриється за адресою: http://localhost:8501

---

## Як завантажити дані

1. Перейдіть на сторінку **📊 Аналіз цін**
2. У боковому меню завантажте **«База постачальників (Excel)»**
3. За потреби завантажте **«Прайс Nokian (Excel)»** (для модуля моніторингу)
4. Перший запуск читає з Excel і зберігає кеш Parquet у папку `cache/`
5. Наступні запуски з тим же файлом (однакові ім'я + розмір) — читають з кешу
6. Кнопка **«Очистити кеш і перезавантажити»** примусово оновлює дані

## Тестові дані

Готові файли для тестування знаходяться у папці `test_data/`:

| Файл | Рядки | Опис |
|------|-------|------|
| `suppliers_base.xlsx` | 500 | 15 постачальників, всі 4 класи, ~60% Nokian |
| `nokian_price.xlsx` | 43 | Рекомендовані оптові ціни Nokian |

Тестові дані містять **навмисні проблеми** для перевірки матчингу:
- Різні формати діаметру: `17`, `R17`, `r17`
- Різний регістр моделі: `Hakka Blue 2`, `HAKKA BLUE 2`, `hakka blue 2`
- Пусті значення в колонці «Усилення»
- Різні формати індексів: `91W`, `91/W`, `W91`
- 10–15 рядків Nokian з цінами нижче рекомендованих (для моніторингу)
- Рядки з `В наличии = 0` (автоматично відфільтровуються при завантаженні)

## Фази розробки

### ✅ Фаза 1 — Готово
- Завантаження Excel з явними dtype для продуктивності
- Parquet-кеш з інвалідацією за іменем і розміром файлу
- Категоріальні колонки для економії пам'яті
- Каскадні розумні фільтри (9 рівнів) з лічильниками
- Збереження наборів фільтрів у `data/saved_filters.json`
- Метрики, 3 типи графіків (Plotly Express)
- Пагінована таблиця (50 рядків на сторінку)
- Експорт відфільтрованих даних в Excel через BytesIO
- Матчинг прайсу Nokian з базою постачальників (`utils/price_matcher.py`)

### 🔧 Фаза 2 — В розробці
- Модуль моніторингу порушень цін Nokian
- Управління контактами Telegram через інтерфейс
- Відправка тексту + Excel через Telegram Bot API (requests)
- Журнал сповіщень у `data/notifications_log.json`

### 🔧 Фаза 3 — Планується
- Авторизація логін/пароль (hashlib SHA-256, ролі admin/analyst)
- Мультимовність UA/RU/EN (перемикач у шапці)
- Динаміка цін у часі
- Розрахунок нетто-цін

## Налаштування Telegram бота (Фаза 2)

1. Створіть бота через [@BotFather](https://t.me/BotFather) → отримайте `BOT_TOKEN`
2. Додайте токен до застосунку (через UI або змінну середовища)
3. Для кожного постачальника отримайте `chat_id` (через `getUpdates`)
4. Заповніть `data/telegram_contacts.json`:
   ```json
   {
     "Назва Постачальника": "123456789"
   }
   ```
5. Застосунок надсилатиме через `POST https://api.telegram.org/bot{TOKEN}/sendDocument`

## Продуктивність

- **Parquet кеш**: повторне завантаження ~10x швидше, ніж Excel
- **Категоріальні типи**: знижують споживання RAM у 3–5 разів для рядкових колонок
- **Явні dtype**: уникнення зайвого inference при читанні Excel
- **Булеві маски + .isin()**: ніяких iterrows у фільтрації
- **Агрегація перед Plotly**: графіки не передають сирі 160к+ рядків у браузер
